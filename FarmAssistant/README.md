# Stardew Valley 农场助手（SMAPI 模组）

**一个快捷键**：**Ctrl+F**（或 **F8**，macOS 上要按 fn+F8）。按下时看你**手里拿的是什么**，触发对应的功能。鼠标右键完全保留原版行为，模组不接管。

| 手持 | 按快捷键 | 进行中再按一次 |
|---|---|---|
| 钓竿 | 开 / 关钓鱼助手：钓鱼小游戏自动操作，可选自动上钩 | 关闭 |
| 水壶 | 开始浇离自己最近（30 格内）的那一片未浇水的作物 | 停止 |
| 种子 | 开始把离自己最近（30 格内）的那一片空耕地种满 | 停止 |
| 斧头 | 找出离自己最近（30 格内）的那一片长成的树、树桩、木垛，以及斧头等级够的大树桩 / 大木头，自己规划顺序一个个砍完（可在配置里改成整张地图） | 停止 |

- **自动浇水**：角色自己走位，按水壶等级蓄力，把这一片浇完；没水时自己走到最近的水边补水。
- **自动播种**：边走边种，把这一片能种的空地种满；种子用完就停。
- **自动砍伐**：默认砍最近的一片树林（相距 4 格以内的目标算连着），也可以设成整张地图。开局排好顺序和倒向；每棵树砍倒、砍树桩一气呵成，把它的掉落物捡光再去下一棵。
- **钓鱼助手**（原独立模组，已并入）：钓鱼小游戏里每一刻由它决定按住还是松开。每次进入存档时都是关闭的。

自动浇水、播种、砍伐进行中，**按任意键**（走路、点鼠标、按手柄等，快捷键本身除外）都会立即停下，交还控制。

## 原则：只替玩家按键

模组不改任何游戏数据：不瞬移，不直接把耕地设成已浇水或已种植，也不改体力、水量、种子数。

| 操作 | 实现 |
|---|---|
| 走路 | 按住方向键（把键并进游戏每帧读取的键盘状态），可以两个键一起按着斜走。速度、碰撞、跑 / 走都由游戏处理 |
| 浇水 | 转向目标，再像游戏处理"按下工具键"那样开始使用工具；需要蓄力时按住工具键，到档后松开，由游戏结算浇到哪些格子 |
| 不蓄力浇身边一格 | 等同于用鼠标点身边 3×3 内的那一格（玩家同样能做到） |
| 补水 | 走到水边，面朝水按一下工具键 |
| 砍伐 | 面朝目标，像游戏处理"按下工具键"那样开始使用斧头（斧头不蓄力，游戏起手后自己挥出），伤害、体力、掉落都由游戏结算 |
| 捡掉落物 | 只是走到能把掉落物吸过来的格子上等着，掉落物由游戏自己飞进背包 |
| 播种 | 调用游戏处理"右键放置物品"的同一个函数（`Utility.tryToPlaceItem`）：只能种在角色身边 1 格内，由游戏检查季节、扣种子。每 0.1 秒最多种一格，和原版按住右键时的自动重复一样快 |

体力、水量、种子照常消耗。体力不够下一次浇水（剩余低于 10）时会停下，不会把人累倒。

## 规划

1. **范围**：从离自己最近的那一格目标出发，沿耕地蔓延（包括已浇的、已种的、空的耕地；浇水时还包括室内花盆），相距不超过 3 格就算连着。
   - 浇水时，其中未浇水的作物就是目标；播种时，其中的空耕地就是目标。
   - 先手动处理过的一条不会把一片地切成两半。
2. **增量**：每做一步之前，都在规划区域里重新看一遍。
   - 新锄的、并且连着这片地的耕地会并进来。
   - 浇水时，有人在空地上新种的作物也会被浇到。
3. **下一步**：枚举所有可达的站位，算出每个动作能完成多少新格子，再按时间算代价。
   - 浇水的动作是"站位 × 4 个朝向 × 当前水壶能蓄到的档位"。代价包括走路、蓄力（每档 0.6 秒）、挥动，以及体力和用水的折算。
   - 播种的动作是"站到这里，把身边 8 格种上"，代价包括走路和每格 0.1 秒。
   - 水壶形状都是矩形，所以先做一次二维前缀和，之后每个候选都只需查表一次。
4. **往后看一步**：对单步效率最高的 6 个候选，各自再算一次接下来的最好一步，选两步合计效率最高的那个。这样不容易留下零散格子。
5. **每做完一个动作就按游戏实时状态重新规划**。
   - 联机时队友做过的格子会自动跳过。
   - 正在走去的那一步如果有一半以上的格子被队友做了，会当场改道。
   - 出手浇水前还会再确认一次，目标格已经被浇过就不白浇。
6. **做不到的格子会跳过**，结束时提示完成了几格、跳过了几格。
   - 初级水壶浇不到 3×3 藤架中间那格，因为四周都走不到。铜壶以上可以从外面蓄力隔着藤架浇到，规划会自动选这种方式。
   - 藤架作物（啤酒花、葡萄、青豆等）种下后那格就不能走了，所以只在站定时种，而且种之前会检查会不会把剩下的地或自己围死，会的话就跳过那格。
   - 混合种子在春天可能种出青豆，所以春天（以及室内、姜岛这类不分季节的地方）也按藤架作物处理；种下后按实际长出的作物更新那格能不能走。
   - 连续两次没成功的格子不再尝试。

浇水的形状与游戏一致：

| 档位 | 范围 |
|---|---|
| 1（不蓄力） | 1 格 |
| 2（铜壶） | 前方 3 格 |
| 3（钢壶） | 前方 5 格 |
| 4（金壶） | 3×3 |
| 5（铱壶） | 3 宽 × 6 深 |
| 6（铱壶 + 远程附魔） | 5×5 |

## 砍伐与拾取

**开局排好顺序和倒向**
- 按快捷键时扫描当前地图：长成的野树、树桩、地上的木垛（树枝），以及斧头等级够的大树桩和大木头。
- 范围：默认从离自己最近（30 格内）的那个目标出发，相距 4 格以内的算连着，一直蔓延，砍的就是这一片；配置里打开"砍整张地图"则全图都砍。开始时提示各有多少个。
- 顺序一次排好：从你站的位置出发，每次接最近的那个；再用 2-opt（把路线里交叉的两段反过来接）拉直。几百个目标也只要几毫秒。
- 倒向：游戏在砍最后一斧时看脚的位置，脚在树干中线右边，树就往左倒，否则往右倒；木头、硬木、种子落在倒向那侧离树干 4 格处。每棵树都往"顺序里的下一个"那侧倒：
  - 落点附近有水、出了地图，或者没有可达格能把它吸过来，都会重罚；
  - 在磁力半径之内的距离不算。
  - 站在左右两侧直接决定倒向；站在上下方时，脚在中线左右偏 10 像素来决定。

**每棵树：砍完一次、捡光一次，再去下一个**
1. 走到旁边，砍倒。
2. **不等倒树动画**，在原站位接着砍树桩。倒树途中砍掉树桩，游戏会让这棵树留到倒完，照常生成那堆木头后再移除（`Tree.performTreeFall` 在倒下途中返回 false），所以不会少东西。树桩有 5 点血：普通斧头 5 斧（约 2.4 秒），本来就比倒树的约 2.1 秒长；铱斧 1 斧（约 0.5 秒），每棵树省约 1.6 秒。
3. **捡干净**：
   - 木头还没生成（树还在倒）：先走到预判的那堆旁边等着。站位选能吸到最多件的格子；件数相同时，选走过去步数少的，再相同选离下一个目标近的。
   - 木头生成后，把树干和木头堆周围 6 格内的掉落物捡光。按每件掉落物预判的停稳位置选站位（见下），一站一站地吸，件数相同时往下一个目标那边靠。
4. 去顺序里的下一个。

**预判停稳位置**（`DropPredictor`）
- 读每块碎片当前的位置和速度，照游戏的规则推算到停稳：每刻重力 0.4 像素；落地弹起时竖直速度变为 2/3、水平速度减半，最多弹 2 次；碰墙水平反向；落进水里就没了。
- 每件掉落物的位置取它所有碎片的平均值，和游戏判断吸附用的位置相同。树倒下的那堆木头会向四周散开，只看第一块碎片会站错地方，导致要多走一步。
- 实测规律：一堆木头分 4 件往左、右、上、下抛。左右两件离中心约 1.2 格，最远约 2 格；上面一件约 1.5 格，下面一件约 1 格；约 1～1.6 秒停稳。默认吸附范围（横纵各约 2 格的正方形）站在中心附近，多数时候一次就能吸到 4 件。
- 吸附范围用角色当前的磁力半径：默认 2 格，每个磁铁戒指加 2 格。

**别人中途砍掉的**
- 顺序里被别人砍掉的目标直接跳过。
- 正要去、还没砍过的目标被别人砍掉：不算自己的，也不去捡它的掉落。那些东西会飞向砍它的人。

**最后兜底扫一遍**
- 正常情况下每棵树都已经捡干净了，这一步只处理漏网的。
- 任何可达格都吸不到的不捡，例如在悬崖或栅栏外、正飞向别的玩家；背包装不下的也不捡。结束时提示件数。

**会跳过的情况**
- 树苗和小树：农场上的小树多半是你自己种的，不砍。
- 装了采集器的树：不砍。
- 镇上路边的树：游戏不让砍。
- 斧头等级不够：大树桩要铜斧以上，大木头要钢斧以上。
- 连续 3 斧都没造成伤害的目标。
- 走不到旁边的目标。结束时会提示跳过了几个。
- 果树、石头不归斧头管。

默认只砍一片，农场上想留着的长成大树只要离那片树林超过 4 格就不会被砍。打开"砍整张地图"时它也会被砍，看着它要被砍了就按任意键停下。

## 钓鱼助手

钓鱼小游戏里，把游戏读取"按键是否按下"的那一处（`BobberBar.update` 中给 `buttonPressed` 赋值的地方）换成由控制器给出的按住 / 松开，其余什么都不写。

- 自动上钩：调用 `FishingRod.DoFunction`，与游戏自带的"自动上钩"附魔是同一个调用。
- 不读取鱼的隐藏目标位置（`bobberTargetPosition`）和它的加速度（`bobberAcceleration`），只根据鱼可见速度的变化推断它往哪里游。
- 每轮结束会在 SMAPI 控制台输出一行结果。

**宝箱优先**：放弃完美，但不放弃捕获。
- 先守鱼攒进度。进度足够承担"整趟取箱"（去宝箱、灌满宝箱条、再回到鱼）期间掉的进度后，才出发去拿宝箱。
- 出发后一口气拿完，不中途折返。

## 配置

装了 [Generic Mod Config Menu](https://www.nexusmods.com/stardewvalley/mods/5098) 时，可以在标题画面的"Mod 设置"里改，或在游戏内"选项"菜单拉到最底部改。没装就编辑 `Mods/FarmAssistant/config.json`。

| 键 | 默认 | 说明 |
|---|---|---|
| `ToggleKey` | `"LeftControl + F, F8"` | 快捷键：按当前手持物触发对应的功能。SMAPI 写法，多个用逗号分隔 |
| `ChopWholeMap` | `false` | 砍整张地图；关闭时只砍最近的一片 |
| `CollectDrops` | `true` | 砍完后捡掉落物 |
| `TreasurePriority` | `true` | 宝箱优先 |
| `AutoHook` | `false` | 自动上钩 |

## 性能

每做一步只规划一次，挥一次水壶或种完一站才规划下一次。30×30 的地上，每次规划的耗时：

| 水壶 | 每次规划 |
|---|---|
| 初级 | 约 0.3 ms |
| 铜 | 约 0.4 ms |
| 铱 | 约 1 ms |
| 播种 | 约 0.2 ms |

增量检查每次约 0.05 ms。每次开始时，游戏要逐格判断这片地能不能通行，那一帧会稍慢；之后都走缓存。


**斜着走**：游戏里同时按两个方向键时，每个方向的速度乘 0.707，合起来的速度与直走相同，所以斜走能省掉"先横后竖"的折线。实际行走的路线用 8 方向 A* 算：斜走一格代价 √2；斜穿时两侧相邻格都要能走，免得卡在拐角。

| 目标在 | 只走横竖 | 可以斜走 | 省 |
|---|---|---|---|
| 斜 45°（横竖各 10 格） | 20 格 | 14.1 格 | 29% |
| 横 10 格、竖 2 格 | 12 格 | 10.8 格 | 10% |
| 正前方 10 格 | 10 格 | 10 格 | 0 |

一条 60×40 格的远路，算一次约 55 微秒。浇水、播种、砍伐、拾取都用这套。

## 离线模拟结果（30×30 地，三人各自运行本模组）

用开发时的离线模拟器跑出（模拟器不在仓库中）：走路、蓄力、挥壶按固定时长计，不模拟体力上限，规划器是模组里的同一份代码。

| 场景 | 结果 |
|---|---|
| 浇水：初级 + 铜从西北相邻两格出发，铱从东南出发 | 134 秒浇完 900 格，三人同时完成；白浇 4 次（队友在出手前一瞬浇了同一格） |
| 浇水：途中队友在 100 格空地上种了作物，又在旁边新锄 5×30 并种上 | 全部被并入，共浇 1050 格 |
| 播种：单人 / 三人 | 152 秒 / 60 秒种完 900 格 |
| 播种：途中队友在旁边新锄 5×30 | 全部被并入，共种 1050 格 |
| 藤架种子：每 2 行留 1 行过道 | 600 格全部种完 |
| 藤架种子：整块 30×30、没有过道 | 种了 633 格，其余跳过，人没有被困住 |

## 何时停止

- 做完了，或剩下的都做不到。
- 按了任意键或鼠标。
- 打开菜单、进入事件或对话、换下水壶或种子、离开当前地点。
- 体力不足、附近找不到水源，或种子用完。
- 去同一站的途中被挡太多次。短暂挡路会自动绕开，那格 5 秒后重新判断能不能走（新放的箱子、栅栏会被当作障碍绕开）；到了一站就重新计数。

## 兼容性

- 纯客户端模组。作为客人加入别人的联机房间也能用，只控制本机玩家。
- 分屏：钓鱼助手的开关、预测和每轮记录按玩家分开，两人同时钓鱼互不干扰。
- 方向键和工具键用的是你在游戏设置里绑定的键盘键。上下左右有一个没绑键盘键时，自动操作不会启动，会给出提示。如果工具键只绑了鼠标、没绑键盘键，就只做不蓄力浇水。
- 蓄力时如果鼠标停在工具栏等界面上，游戏会把按下的工具键当成点击界面，所以会等鼠标移开再继续，并提示一次。
- 往花盆里放种子在游戏里走的是另一套交互，自动播种暂不处理花盆。

## 编译

```bash
dotnet build -c Release
```

编译后会自动部署到游戏的 `Mods/FarmAssistant`。需要 .NET SDK 6 或更新、SMAPI 4.x、Stardew Valley 1.6.x。

## 结构

```
ModEntry.cs        入口：快捷键按手持物触发、配置菜单、任意键接管、提示
ModConfig.cs       配置项
Features.cs        手持物 → 功能的对应与图标
AutoTask.cs        三个执行器的共同部分：通用检查、停止、走路时的卡住处理
AutoWaterer.cs     浇水：蓄力 / 挥动 / 补水的逐刻状态机
SeedSower.cs       播种：边走边种、藤架安全检查
TreeChopper.cs     砍伐：扫描全图目标、排顺序（2-opt）、倒向选择、挥斧、树桩、每棵树就地捡光
DropCollector.cs   捡掉落物：按吸附范围选站位、排除捡不到的
DropPredictor.cs   掉落物停稳位置与可吸时刻的预判（照游戏的重力、弹跳规则推算）
FieldPlanner.cs    田地规划：连片与增量、水壶形状、下一步选择、找水源
TileGrid.cs        整张地图的格子寻路：通行缓存、临时封格、比较远近用的 BFS、实际行走用的 8 方向 A*
FieldView.cs       规划器看到的地图（只读游戏状态；浇水 / 播种两种目标）
Walker.cs          沿路线走（虚拟方向键、斜走、对正、脚的偏移、卡住检测）
PlayerInput.cs     虚拟键盘（GetKeyboardState 的 Harmony 后置补丁）与工具起手
Fishing/           钓鱼助手：按键替换补丁、自动上钩、每轮日志；Core/ 为与游戏无关的预测与规划
```
